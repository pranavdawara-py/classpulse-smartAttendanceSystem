# School dashboard and management

## Dashboard

The MVP school dashboard starts with all batches and a separate **Teachers** section. A batch detail opens cards for each assigned teacher-course relationship in that batch; cards should show teacher, subject, applicable timetable/next lecture, student count, and current attendance summary where available.

## Management actions

School manages student accounts, optional roll numbers, batch/sub-batch memberships, teacher assignments, timetable templates, custom student form configuration, and missing-photo/temporary-attendee reconciliation. It can inspect all approved student photos when necessary, while list views use the profile photo by default.

## Audit visibility

Extra, cancelled, and rescheduled lectures show their original/new times where relevant and labels such as `(created by teacher)` / `(cancelled by teacher)` alongside actor and edit time. These are visible in the school system but do not create special MVP notifications.
