# Administrator setup flow

The minimum setup journey is institution profile -> teacher/student records -> groups and memberships -> courses if used -> schedule templates -> face-enrolment readiness. Each screen is list-first, supports empty states with one clear creation action, validates errors near fields, and avoids exposing biometric internals to ordinary lists.

Mobile screens use compact filters and drill-in editing; desktop may use table/list density. The MVP does not need bulk import unless it becomes essential to the demo.
